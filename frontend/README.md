# MercaNova — Frontend

React 19 + Vite + TypeScript (strict) + Tailwind 4 + shadcn/ui + TanStack Query.
Design source of truth: [`docs/PLAN.md`](../docs/PLAN.md) §12 (API) and §13 (frontend).

## Run it

```bash
# whole stack (db + backend + frontend)
docker compose up -d --build        # http://localhost:5173

# frontend only, outside Docker (backend must be up on :8000)
cd frontend && npm install && npm run dev
```

Checks: `npx tsc -b && npx oxlint && npx vite build`.

The browser only calls relative `/api/...`. Vite proxies it to `VITE_API_URL`
(`http://localhost:8000` by default, `http://backend:8000` inside compose), so the backend needs no CORS.

## Layout

```
src/
  api/          client.ts (fetch + ApiError), types.ts (mirror of the backend contract), endpoints.ts
  components/ui shadcn components (generated; do not hand-edit)
  features/     one folder per feature (chat/ today)
  lib/          utils (cn)
  App.tsx       header + catalog area + chat side panel
  main.tsx      QueryClientProvider + Toaster
```

Types in `api/types.ts` mirror Pydantic models in the backend. When a backend schema changes, update them in the same change.

### Not done yet (in the order we plan to build it)
Backend endpoints for most of these do not exist yet; until they do, build the UI against the contract in `docs/PLAN.md` §12 (idea: MSW mocks, switched off per endpoint as the real one lands).

1. **Catalog + product detail** (RF-01, N4): grid, filters (category, brand, price, in stock), detail with specs and stock per warehouse. Needs `GET /api/products`, `/api/products/{id}`, `/api/categories`, `/api/warehouses`.
2. **Product cards in the chat** (AGENTS.md rule 11): today `product_ids` render as plain chips. Needs `GET /api/products?ids=`. Also the **comparison table** (RF-06) once the agent returns it.
3. **Login / register** (N3): needs `/api/auth/*`. Chat is currently anonymous (no login in the backend yet).
4. **Cart drawer** (RF-09/10, N5): add, +/−, remove, total, inline stock errors. Needs `/api/cart*`.
5. **Checkout** (RF-11, N6): shipping vs pickup, pickup branches with availability, simulated payment, summary, **confirmation modal** (action, products, quantities, unit price, total), handling of `PRICE_CHANGED` / `OUT_OF_STOCK` (409). Needs `/api/checkout*`, `/api/orders/{id}/confirm`.
6. **Confirmation screen + order history** (RF-14/16, N7): needs `/api/orders*`.
7. **Voice input** 🎤 (RF-08, N12): record audio → `POST /api/transcribe` → send as a normal message.
8. **Chat ↔ UI integration** (§13): `ui_actions`, `pending_confirmation` card for remove/clear, `undo_token` toast, checkout prefill (extras E3/E4).
9. **i18n dictionary** for categories, attributes and stock states (names and values stay in their original language).
10. Router (react-router is installed but not wired yet) and the pages that go with it.

### Known limitations / notes
- No tests for the frontend yet (the project has no E2E requirement; backend tests are the priority, `docs/PLAN.md` §16). Add component tests only if time allows.
- The Docker image runs the Vite **dev server** (fine for a local prototype, not a production build).
- `src/components/ui/*` is generated by shadcn (`npx shadcn@latest add <component>`); it imports `cn` from the `cn` package by design of the current shadcn version.
